# CCF 推荐国际学术会议和期刊目录

一个轻量级的静态网页，用于查询中国计算机学会（CCF）推荐的国际学术会议和期刊。

## 功能

- 按**领域**筛选（10 个方向，如数据库、人工智能、计算机网络等）
- 按**等级**筛选（A / B / C 类，支持多选）
- 按**类型**筛选（会议 / 期刊）
- 三个条件同时生效（AND 逻辑），结果实时更新
- 点击网址可直接跳转至对应 DBLP 页面

## 数据

`data/processed/ccf.json` 包含 **682** 条记录，每条记录字段如下：

| 字段 | 说明 |
|------|------|
| 全称 | 期刊 / 会议全名 |
| 出版社 | 如 ACM、IEEE、Springer |
| 网址 | DBLP 链接 |
| 领域 | 所属学科方向 |
| 等级 | A / B / C |
| 类型 | 期刊 / 会议 |

## 使用方法

无需任何构建工具，直接用 Python 启动本地服务器：

```bash
python3 -m http.server 8787
```

然后在浏览器中打开 [http://localhost:8787](http://localhost:8787)。

> 注意：需通过 HTTP 服务器访问（不能直接双击打开 `index.html`），因为页面通过 `fetch` 加载 JSON 数据文件。
